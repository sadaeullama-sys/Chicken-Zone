# TU Chicken Zone Android Flutter Project

Upload the contents of this ZIP to the root of the GitHub repository. Preserve `.github/workflows/main.yml`.

Run GitHub Actions → Build Chicken Zone APK → Run workflow. Download the `Chicken-Zone-APK` artifact after the run succeeds.

Starter features: styled dashboard, purchase/sale/expense/customer-credit entries, basic totals/reports, shop name setting, local storage.

This is a starter version, not a fully audited commercial accounting app. PDF export, detailed customer profile/ledger, weight-stock reconciliation, backup export/import, cloud sync, and secure license validation remain future work.
